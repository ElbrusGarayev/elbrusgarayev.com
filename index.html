About

A little about me.

For me, backend development isn’t just about writing code — it’s about system thinking, structure, and building for the long term.

I’ve spent six years at ABB, one of Azerbaijan’s largest banks, growing from junior to lead and now senior backend developer. My work lives in the Java and Spring Boot ecosystem: microservices, payment flows, and event-driven integrations on Apache Kafka, backed by Oracle and MongoDB.

I value structured technical analysis, honest estimation, and well-planned sprints. The goal isn’t just working code — it’s results that are measurable and sustainable. Increasingly, that means focusing on software architecture, system design, and helping teams make good technical decisions together.
